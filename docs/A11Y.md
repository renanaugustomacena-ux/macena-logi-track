# LogiTrack — Accessibility

Target: WCAG 2.1 Level AA across the dashboard and the Italian
landing page. Primary locale: it-IT; English translations for
selected sales-surface copy only.

## Structural baseline

- `<html lang="it">` at root.
- `<header>`, `<main>`, `<nav>`, `<footer>` landmarks named in Italian
  via `aria-label` attributes.
- Skip link `"Vai al contenuto principale"` first focusable element
  on the landing page.
- Heading hierarchy: exactly one `<h1>` per page; no skipped levels.
- Minimum touch target 44×44 px on actionable controls.

## Focus management

- Visible focus ring on all interactive elements (Tailwind `focus:ring`
  classes + default browser outline preserved).
- No outline suppression except inside the Leaflet map container
  where the Leaflet library draws its own focus.

## Colour contrast

- `--logitrack-teal` #0f4c5c on white: 10.8 : 1 (passes AAA).
- `--logitrack-blue` #1d4ed8 on white: 7.1 : 1 (passes AAA).
- `--logitrack-amber` #f59e0b used only on dark backgrounds (amber-on-
  slate-900 8.2 : 1).

## Keyboard-only walk-through (Dashboard)

1. `Tab` — skip link ("Vai al contenuto principale").
2. `Enter` — jumps to main.
3. `Tab` — filters (stato → vettore → dal → al → aggiorna).
4. `Tab` — first row in the shipment table; arrows navigate rows if
   the user has a screen-reader in browse mode.
5. `Enter` on a row → Shipment Detail view.

## Keyboard-only walk-through (Shipment Detail)

1. `Tab` — "Torna all'elenco" link.
2. `Tab` — map container (focusable; Leaflet captures arrow keys).
3. `Tab` — timeline list, traversable with arrow keys.

## ETA accessibility

- ETA label uses `aria-live="polite"` so screen readers announce
  updates without interrupting navigation.

## Landing page

- Italian only (G16). Verified with `axe-core` via Playwright to
  return 0 serious/critical issues.
- Form fields include `autocomplete` attributes for the expected
  contact-info fill (name, email, organisation).

## Known gaps

- Leaflet tooltips are not screen-reader friendly by default; we
  supplement with `bindPopup` popups that ARE announced when opened
  via keyboard (`Enter` on the map).
- The chart in the Dashboard uses Tailwind classes without an
  `<svg title>`; the adjacent text serves as the programmatic label.
